## CÁCH ĐỌC BẢNG

| Cột | Ý nghĩa |
| :--- | :--- |
| **P · Kỹ thuật · Tầng** | **P1** = smoke, bắt buộc xanh trước khi merge; **P2** = regression; **P3** = thấp, chấp nhận rủi ro tồn dư. **Kỹ thuật:** `EP` phân vùng tương đương, `BVA` giá trị biên, `DT` bảng quyết định, `ST` chuyển trạng thái, `EG` đoán lỗi (từ rủi ro R-xx), `SEC` an toàn. **Tầng:** `JUnit` (Tuần 2), `Selenium` (Tuần 3-4), `API` (gửi HTTP trực tiếp, vượt qua kiểm tra của trình duyệt), `Tay` |
| **Loại** | Positive / Negative |
| **🔶** | *Defect candidate*: ca nhằm xác nhận giả thuyết lỗi R-xx trong SPECIFICATIONS mục 11. Nếu hệ thống trả HTTP 500 hoặc không như mong đợi thì ghi nhận là **lỗi thật** |
| Biên dạng `n/m` | Thử cả hai phía biên: `n` ký tự (hợp lệ/không hợp lệ) và `m` ký tự (phía còn lại) |
